# Модель данных

Таблица `responses` хранит одну строку на одну анкету. Источник строки задаётся полем `source`: `paper` для очного бумажного ввода и `online` для публичной онлайн-анкеты.

## Поля

- `id` — UUID анкеты.
- `survey_date` — дата опроса в формате `YYYY-MM-DD`.
- `gender` — `male` или `female`.
- `age_group` — `under_18`, `18_40`, `over_40`.
- `residence` — `snezhinsk` или `other`.
- `source` — `paper` или `online`.
- `q4`...`q16` — `yes`, `no`, `unknown`.
- `q11_war_details` — свободный текст по войне или `—`.
- `research_territory` — необязательная территория поиска из онлайн-анкеты.
- `research_period_start`, `research_period_end` — необязательные годы исследуемого периода.
- `free_text` — необязательный свободный комментарий из онлайн-анкеты.
- `contact_name`, `contact_phone` — необязательные контактные поля из онлайн-анкеты, показываются при ответе `yes` на вопрос 16.
- `consent_to_data_processing` — nullable-отметка согласия публичного респондента
  на обработку ответов.
- `consent_to_events` — совместимое nullable-поле отдельного согласия на
  приглашения. Стабильный production-интерфейс его пока не собирает.
  В обоих полях `NULL` означает, что отметка не фиксировалась.
- `is_fake` — `true` только для тестовых строк, сгенерированных через интерфейс. Реальные анкеты имеют `false`.
- `deleted_at` — время перемещения анкеты в корзину. `NULL` означает активную
  анкету.
- `created_at`, `updated_at` — ISO-даты.

Обычное удаление анкеты заполняет `deleted_at`. Все активные запросы репозитория
добавляют условие `deleted_at IS NULL`, поэтому корзина не влияет на фильтры,
аналитику и CSV. Восстановление очищает `deleted_at`.

Массовое удаление фейковых строк физически удаляет только записи с
`is_fake='true'`, включая фейковые строки в корзине.

## PDF-архив

Таблица `survey_pdf_files` хранит метаданные PDF-файлов со сканами бумажных анкет.

- `id` — UUID файла.
- `survey_date` — дата мероприятия в формате `YYYY-MM-DD`, вычисляется из имени `ггггммдд_анкеты.pdf`.
- `display_name` — имя, заданное оператором и показываемое в интерфейсе.
- `original_file_name` — исходное имя загруженного файла.
- `stored_file_name` — техническое имя файла на диске.
- `mime_type` — MIME-тип загрузки.
- `size_bytes` — размер файла.
- `created_at`, `updated_at` — ISO-даты.

Физические PDF не лежат в публичной папке фронтенда. API хранит их в `RODOVED_PDF_DIR`, если переменная задана, иначе рядом с SQLite-базой в каталоге `pdf-files`.

## Вопросы

Канонический список вопросов находится в `packages/shared/src/index.ts`. UI и API используют его как единый источник правды.

## Миграции

Миграции хранятся в `packages/db/migrations`. При старте API вызывается кодовая миграция из `packages/db/src/migrate.ts`.

- `0001_initial` — базовая таблица анкет и индексы.
- `0002_fake_responses` — признак `is_fake` и индекс для безопасного удаления фейковых строк.
- `0003_survey_pdf_files` — метаданные PDF-архива и индексы по дате/именам файлов.
- `0004_online_responses` — источник анкеты и дополнительные поля публичной онлайн-анкеты.
- `0005_response_contacts` — контактные поля онлайн-анкеты для запроса помощи.
- `0008_response_consents` — nullable-отметка согласия на обработку данных.
- `0010_response_trash` — время мягкого удаления и индекс корзины.

Номера `0008` и `0010` сохранены совместимыми с экспериментальной веткой. Пропуски
в последовательности допустимы: миграции идентифицируются строковым `id`, а не
порядковым счётчиком.
