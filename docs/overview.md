# Обзор проекта

`snz-rodoved` — веб-приложение для переноса физических опросов в базу и анализа результатов.

Основной пользователь v1 — один рабочий/оператор, который вручную заносит анкеты и сам смотрит аналитику. Публичная страница существует по основному адресу, но не раскрывает статистику.

Рабочая зона поддерживает ноутбук и телефонный сценарий. На узких экранах используется нижняя навигация, крупные кнопки ответов, закрепленное сохранение анкеты и карточный вид строк данных.

## Основные маршруты

- `/` — публичная страница с кратким описанием, гостевым переходом к открытой информации и активными контактами.
- `/survey` — публичная онлайн-анкета без входа в рабочую зону.
- `/login` — вход в рабочую зону по паролю.
- `/editor` — ввод новых анкет.
- `/data` — фильтры, PDF за выбранный период, свернутые графики, таблица, редактирование и CSV-экспорт.
- `/pdf` — загрузка, хранение, скачивание и удаление PDF-сканов бумажных анкет.
- `/admin` — отдельный вход администратора по логину и паролю, управление паролями доступа.
- `/api/*` — API Fastify.

## Важные правила данных

- Бумажные структурированные анкеты обычно не содержат ФИО и телефона. Онлайн-
  анкета может сохранить имя и телефон только в ветке запроса помощи по Q16.
- Поле `source` разделяет очные анкеты (`paper`) и публичные онлайн-анкеты (`online`).
- Онлайн-анкета может содержать `researchTerritory`, `researchPeriodStart`, `researchPeriodEnd` и `freeText`; эти поля нужны для описания направления поиска, но не должны превращаться в сбор контактов.
- Если в онлайн-анкете на вопрос 16 выбран ответ «Да», форма показывает поля имени
  и телефона. Телефон проходит серверную проверку, а публичная отправка требует
  отметку согласия на обработку ответов.
- Контакты доступны только в защищённой рабочей зоне, скрыты в таблице по
  умолчанию и исключены из основного CSV. CSV с контактами формируется отдельным
  подтверждаемым действием.
- Пропуск или нечитаемый ответ хранится как `unknown`.
- Вопросы 7 и 8 — отдельные поля, потому что оба есть в бумажной анкете.
- `q11WarDetails` заполняется текстом или `—`, если уточнения нет.
- Фейковые анкеты имеют отдельный признак `isFake`; массовое удаление фейковых строк не удаляет реальные анкеты.
- Обычное удаление анкеты обратимо: строка попадает в корзину и перестаёт
  учитываться в активных данных до восстановления.
- PDF-сканы бумажных анкет хранятся отдельно от структурированных строк анкет и доступны только после входа в рабочую зону.
- Имя PDF задается вручную в формате `ггггммдд_анкеты.pdf`; дата для фильтрации берется из имени файла.
- Публичная страница в v1 не раскрывает статистику и не дает гостям доступ к рабочим данным.
